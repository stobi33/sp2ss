Touchstone → RNM

Turning a PDN S-parameter file into a state-space model

A rational-fitting pipeline that ends in a handful of multiply-accumulates per timestep, with the four decisions that determine whether it works.

What you are building

An RNM load model is a current source that wants a voltage back. So the target is a discrete recurrence the simulator can evaluate once per timestep:

x[n+1] = Ad·x[n] + Bd·i[n] v[n] = Cd·x[n] + Dd·i[n] + (E/Ts)·(i[n] − i[n−1])

i = current injected into each port [A], v = port voltage [V].

On a 2-port PDN spanning 1 kHz to 5 GHz, that lands at six states — about forty multiplies per timestep. A 4-port extraction of the same network lands at eight.

The sequence

Eight steps

  1. 01
    Read the Touchstone file
    Two traps: 2-port data is ordered S11 S21 S12 S22 while every other port count is row-major, and v1 .s2p files may carry a noise block after the network data.
  2. 02
    Convert S to Z
    Z = √Z₀ (I−S)⁻¹ (I+S) √Z₀ — the driving-point impedance is what maps current to voltage.
  3. 03
    Vector fitting
    Relaxed Gustavsen–Semlyen iteration in real arithmetic, one common pole set for every matrix entry, unstable poles reflected into the left half plane.
  4. 04
    Realize
    Real modal form: a 2×2 block [[σ,ω],[−ω,σ]] per conjugate pair, so the state update costs ~2 multiplies per state instead of n.
  5. 05
    Balanced truncation
    Drop states with negligible Hankel singular values. This is where 200 states become 8.
  6. 06
    Passivity
    Positive-real Hamiltonian test; enforce by perturbing C only, so the poles — and therefore stability — are untouched.
  7. 07
    Discretize
    Zero-order hold at the RNM timestep. ZOH is exact for the staircase current an RNM driver actually produces.
  8. 08
    Emit
    SystemVerilog, Verilog-AMS wreal, C, Python, JSON, and a testbench.
What actually decides the outcome

Four decisions

Steps 1–8 are mechanical. These four are not, and each one is the difference between a model that works and one that quietly does not.

Decision 01 · fit Z, not S

Fit the quantity the simulator consumes

Converting S per timestep is both wrong and expensive. Fit the driving-point impedance directly and the recurrence falls out.

Decision 02 · relative weighting

Weight the least-squares by 1/|Z|

PDN impedance spans four or five decades. Plain least squares fits the anti-resonant peaks and throws away the milliohm mid-band you actually care about. On the reference network that is a 40× worse worst-case error — 1.40% unweighted against 0.034% weighted.

Decision 03 · keep the s·E term

A PDN is inductive at the top of the band

Measure the slope of |Z₂₂| over the last decade and it is +1.00 — purely inductive. Without an s-proportional term, vector fitting has exactly one way to synthesize a rising |Z|: run a pole off toward infinity with a residue that cancels against the constant term.

The failure this causes

The fit looks fine. It reports 3.4e−4 relative error. But it has placed a pole at 1.3e14 Hz with residue 1.4e20, cancelling against d = 1.6e5 — an internal dynamic range of roughly 1e8 on a milliohm network. That destroys balanced truncation and burns precision in the emitted HDL, and nothing in the error metric tells you.

Admit the s·E term and the same fit becomes 100× more accurate while the numbers turn physical: d is the DC resistance and E is the port inductance matrix.

Decision 04 · realizing s·E

One FIR tap, not a pole and not bilinear

A symmetric real E is a lossless inductance — it contributes nothing to the Hermitian part, so it needs no state at all. Three ways to discretize it, only one of which survives:

  • Bilinear puts a pole at z = −1. It rings at Nyquist forever.
  • A band-limiting pole works, but pushing the corner far enough out for under 1% error re-inflates D by E·ωc and brings decision 03's cancellation straight back. A differentiator is a pole at infinity.
  • One FIR tap, (E/Ts)(i[n]−i[n−1]), is unconditionally stable, tends to jωE at low frequency, and is exact whenever the current is piecewise linear over a sample.
Validation

Do not test against a zero-rise-time step

An instantaneous current step puts infinite dv/dt across the port inductance. Measured that way, a perfectly good model reports 98% error — you are measuring an impulse the coarse grid cannot resolve, not the model.

Give the current a one-sample slew instead. It is physically honest, it is the case the FIR branch is exact for, and against a 64× oversampled reference the same model then reports 1.2e−4.

Two more things that bite

Order search and the noise floor

Reduced-order error is not monotone in retained order. Cutting between two near-equal Hankel singular values makes the balancing transform ill-conditioned, so a deeper cut can beat a shallower one. On the 4-port network, order 150 gives 3.1e−3 while order 20 gives 1.2e−4. A bisection search would have missed the 8-state answer entirely; a geometric ladder with downward refinement finds it.

Relative weighting will chase the VNA noise floor. Below roughly a milliohm, a 50 Ω-referenced S-parameter is mostly noise. The smallest |Z| in the reference network is 14 µΩ, so 37 µΩ of measurement noise makes that sample meaningless and the raw relative error reads 631% for a model that is fine. Clamp the weight denominator at the smallest impedance you trust and the same model reports 12.8%.

Better still: export Z-parameters directly, or renormalize to a low reference impedance. Round-tripping milliohms through a 50 Ω S-parameter at nine significant digits costs about 25 nΩ of quantization before any real noise.

Choosing Ts

Bandwidth, not stability

ZOH is exact for the state part under a staircase input, so stability is not the binding constraint — bandwidth is. Target Ts ≤ 1/(20·f_max) for the highest frequency whose droop matters, which is rarely the top of the Touchstone file.

If the model carries a series inductance, the FIR branch adds a half-sample lag worth about π·f·Ts. Twenty points per cycle costs roughly 16% on the inductive part alone; a hundred points per cycle costs about 3%.

Running it

Commands

# build the model, search for the smallest state count
python sp2ss.py pdn.s2p --order 40 --reduce-target 1e-3 \
       --ts 5e-12 --weight-floor 1e-3 --plot

# reduce a multi-port extraction to the ports you actually drive
python sp2ss.py pdn.s4p --ports 1 4 --unused open --order 60

Then clock the generated module at exactly TS. Changing the sample rate invalidates the model — re-run with the new --ts.

pdn_ss_rail #(.VNOM(0.8), .TS(5e-12)) u_pdn (
    .clk(clk_5ps), .rst_n(rst_n),
    .i_load0(i_die), .i_load1(i_vrm),   // current drawn, positive
    .v_rail0(v_die), .v_rail1(v_vrm)    // v = VNOM - Z*i
);

Vector fitting after Gustavsen & Semlyen (1999) and the relaxed pole relocation of Gustavsen (2006); passivity enforcement after Grivet-Talocia (2004). All figures above are measured on a synthetic PDN with a known answer — VRM, board bulk, package and on-die decoupling — so the recovered DC resistance and port inductances can be checked against the network that produced them.
